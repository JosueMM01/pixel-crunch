# Textos y evidencia de terceros

Esta carpeta conserva textos de licencia y avisos necesarios para auditar la futura distribución de eliminación de fondo:

- `PIXEL-CRUNCH-MIT-HISTORICAL.txt`: licencia de las versiones publicadas antes de la migración, incluido `main` en `99e7b7b`.
- `ONNXRUNTIME-MIT.txt`: licencia de ONNX Runtime 1.21.0.
- `ISNET-APACHE-2.0.txt`: licencia publicada por el repositorio DIS citado por IMG.LY.
- `IMGLY-WEB-1.7.0-ThirdPartyLicenses.json` y `IMGLY-DATA-1.7.0-ThirdPartyLicenses.json`: avisos extraídos de los artefactos 1.7.0 auditados.

La licencia AGPL incluida por IMG.LY coincide con la familia de `LICENSE`; los artefactos originales deben conservar además su propio `LICENSE.md` cuando se incorporen en la Fase 4.
